Prática Rápida:

A seguir vamos para prática que não tão detalhada de tudo que aprendemos na aula principal:

Voltar para página inicial

Vamos là:

1° Começaremos com as tags de cabeçalhon que seguem um padrão de hierarquia. Vamos aprender como esse padrão funciona:

1.1 Começaremos com o titulo principal do site que é usada a tag <h1>, essa tag só pode ser usada apenas uma vez por pagina caso contrario pode resultar em problemas de SEO.

1.2 Dando sequencia temos a tag de titulo <h2> que pode ser usada para criar subtítulos. Essa tag pode ser repetidas quantas vezes necessário.

1.3 Agora temos a tag de titulo <h3> que pode ser usada para criar sub-subtítulos. Essa tag também pode ser repetidas quantas vezes necessário.

1.4 Para finalizar o topicos de titulos temos uma curiosidade util as tags de h4 até h6 são usados com pouquissima frequência e elas seguem o mesmo raciocínio das tags de H2 e H3.

2.1 Começaremos pela tag <b> que deixa o texto escrito nela em negrito. Mais tambem temos outra tag para deixar o texto em negrito <strong> ela serve para dar enfase ao texto.

2.3 Vamos ver agora a tag de quebrar linha: <br>. Serve para criar uma quebra de linha no texto. Como mostrarei a seguir:

2.4 Vamos ver a tag que para deixar o texto em itálico: <i> . Serve para deixar o texto em itálico. Exemplo: Texto em itálico

2.5 Vamos ver a tag que para deixar o texto em sublinhado: <u> . Serve para deixar o texto em sublinhado. Exemplo: Texto em sublinhado

2.6 Vamos ver a tag que para deixar o texto em exposição: <sup> . Serve para deixar o texto em exposição. Exemplo: 102. Muito util para colocar numeros no expoente.

2.7 Vamos ver a tag que para deixar o texto em subscrito: <sub> . Serve para deixar o texto em subscrito. Exemplo: H2O. Muito util para colocar numeros no subscrito.

2.8 Agora vamos ver como deixar o texto riscado: <del> Serve para indicar que um texto foi removido. Exemplo: Texto riscado.

2.9 Agora vamos ver a tag de como deixar o texto pequeno: <small> Serve para indicar que um texto é menos importante. Exemplo: Texto pequeno.

2.10 Para finalizar as tags de formatação de texto vamos aprender a como marcar o texto: <mark>. Muito util para destacar partes importantes do texto. Exemplo: Texto marcado.

3.4 Vamos aprender a tag de endereço: <address>. Serve para exibir informações de contato. Exemplo:

Essa tag por si só não tem um estilo específico, mas é usada para agrupar informações de contato. E ela já vem configurada com o itálico.

Essa tag ela quando você coloca o texto nela automaricamente o resultado desse texto na pagina fica entre aspas como usado no exemplo.
