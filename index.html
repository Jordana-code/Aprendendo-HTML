Copilado de Tudo que Aprendi no HTML

Nesse colpilado vamos revisar tudo que aprendemos sobre HTML.

O que são tags?

Tags são elementos que definem a estrutura e o conteúdo de uma página web.

Tags de Cabeçalho

As tags de cabeçalho são: <H1>, <H2>, <H3>, <H4>, <H5> e <H6>, porem da <H4> para frente é menos comun de se usar.

OBS: A TAG DE <H1> DEVE SER USADA APENAS UMA VES POR PAGINA

Tags de Formatação de texto:

As tags de formatação de texto são usadas para dar estilo ao conteúdo da página. Vamos aprender como usá-las:

Vamos começar com o negrito podemos usar o <strong> e o <b>. O <strong> ele serve para dar enfase ou seja a maquina lê ele como destaque e o <b> ele só deixa em negrito mesmo.

Agora da linha de divisão: <hr> ela serve para criar uma linha que divide o conteúdo.

Vamos tambem ver a tag para deixar o texto em italico: <i>Texto em itálico</i>

Agora vamos ver a tag para deixar o texto em sublinhado: <u>Texto em sublinhado</u>

Agora vamos ver a tag para deixar o texto em exposição: <sup>Texto em exposição</sup>

Agora vamos ver a tag para deixar o texto em subscrito: <sub>Texto em subscrito</sub>

Agora vamos ver como deixar o texto pequeno: <small>Texto pequeno</small>

E por fim vamos ver como deixar o texto rabiscado: <del>Texto rabiscado</del>

Essas são as tags de formatação de texto que aprendi em HTML

Agora vamos aprender a tags de Citação:

As tags de citação são usadas para indicar citações, abreviações, endereços e títulos de obras. Vamos aprender como usá-las:

Vamos começar pela tag de abreviação: <abbr title="texto completo">Texto Abreviado</abbr>. Serve para exibir a descrição completa quando o usuário passa o mouse sobre o texto abreviado.

Agora vamos ver a tag para endereço: <address>Rua, bairro cidade</address>. Serve para exibir informações de contato.

Agora vamos ver a tag para título de uma obra: <cite>Filme, Livro e Poema...</cite>. Serve para indicar o título de uma obra.

Agora vamos ver a tag para citação: <q>Texto da Citação</q>. Serve para citar trechos de textos.

E por fim vamos ver a tag para trecho destacado de artigo: <blockquote>Texto a ser destacado </blockquote>. Serve para destacar trechos de textos.
