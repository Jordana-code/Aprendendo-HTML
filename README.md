# Aprendendo HTML

Bem-vindo(a) ao meu repositório de estudos e práticas de **HTML (HyperText Markup Language)**! Este espaço documenta minha evolução no desenvolvimento web, contendo os conceitos fundamentais, marcações semânticas e boas práticas que estou aplicando na prática.

🔗 **Acesse o site no ar:** [https://jordana-code.github.io/Aprendendo-HTML/](https://jordana-code.github.io/Aprendendo-HTML/)

---

## Conteúdo do Repositório

O repositório está organizado de forma a abranger desde os conceitos básicos da estrutura de uma página web até elementos mais avançados de semântica e formulários:

* **Fundamentos da Web:** Estrutura básica de um documento HTML (`<html>`, `<head>`, `<body>`), metadados e codificação de caracteres.
* **Textos e Tipografia:** Uso de títulos (`<h1>` a `<h6>`), parágrafos (`<p>`), ênfases (`<strong>`, `<em>`) e quebras de linha.
* **Listas e Tabelas:** Organização de dados com listas ordenadas, não ordenadas e tabelas estruturadas.
* **Links e Mídias:** Inserção de hiperlinks, imagens, áudios e vídeos.
* **Formulários:** Elementos de entrada de dados (`<input>`, `<select>`, `<textarea>`, `<button>`) e validações básicas.
* **HTML Semântico:** Utilização correta de tags como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` e `<footer>`.

---

## Tecnologias Utilizadas

* **HTML5:** Linguagem de marcação principal para estruturação do conteúdo.
* **GitHub Pages:** Plataforma utilizada para o deploy e hospedagem contínua do site.
